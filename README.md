# AI 理專對練教練（Demo）

## 怎麼用
1. 雙擊 `start.bat`，會自動用 Edge 打開
2. 選一位客戶 → 接聽 → 直接開口講（或打字）
3. 按「結束並評分」看報告

建議戴耳機，不然客戶的聲音會被麥克風收進去。

注意：選本機大腦時，客戶扮演和評分在本機跑；但「聽你說話」用的是瀏覽器內建語音辨識，聲音會送到 Google／微軟的雲端。要完全離線，之後要換成本機語音辨識。

## AI 大腦
左邊選單「AI 大腦」有兩個設定，分開選：
- **文字大腦**：扮演客戶（一般通話）、即時教練、最後評分、「用 AI 幫我寫」都用它。可選本機模型、Gemini、ChatGPT 方案、Azure OpenAI、OpenAI。左下角的選單也能切換。
- **即時通話（Gemini Live）**：開了之後通話改用 Gemini Live（見下一段）；教練和評分還是用文字大腦。

主要大腦太忙或不能用時，會自動改用備援（Gemini，或已經暖好的本機模型），畫面上會跳通知。

## 用 ChatGPT 方案當大腦（本機）
用你自己的 ChatGPT Plus 或 Pro 方案，不用另外付 API 費用。
1. 執行 `start.bat` → 左邊「AI 大腦」→ 按「Continue with ChatGPT」
2. 用自己的帳號登入、按同意，會自動回到對練畫面，文字大腦換成 ChatGPT
3. 卡片上可以選模型（教練每句都要跑，選快一點的）；「Manage usage」可以到 ChatGPT 看用量

要知道的事：
- 只限你本人的帳號，不能給別人共用（OpenAI 的規定）
- 公司的 ChatGPT Business／Enterprise 帳號可能不能用
- 登入資料存在這台電腦的 `.chatgpt/` 資料夾，不會上傳；要停用就按「登出」
- 用量到上限、登入過期或 ChatGPT 暫時不能用時，自動改用備援；登入過期就再按一次「Continue with ChatGPT」
- OpenAI 目前可能有續期的問題，有時大約每小時就要重新登入一次
- 即時通話（Gemini Live）不受影響，聲音還是走 Gemini

## 即時對話（Gemini 3.8 Live）
「AI 大腦」頁打開「即時通話（Gemini Live）」，通話就像真的講電話：客戶講到一半你可以直接插話，它會停下來聽；不用按麥克風，也不用等停頓。
- 要先在「聲音設定」選 Gemini、貼上金鑰
- 以前左下角選「Gemini」的，更新後即時通話會維持開著，用起來和原本一樣
- 麥克風整通電話都開著，點麥克風鍵可以靜音；一定要戴耳機，不然客戶會聽到自己的聲音而被打斷
- 教練和評分用文字大腦；選 Gemini 時，即時教練用較快的 gemini-3.1-flash-lite
- 你說的話會即時送到 Google。免費版的額度小、尖峰時常塞車，正式使用請在 AI Studio 開啟付費

## 換成好聽的聲音
左邊選單「聲音設定」→ 選 ElevenLabs、Gemini 或雅婷 → 貼上 API 金鑰 → 幫每位客戶挑聲音。
金鑰會存在 `.env`，不要把 `.env` 傳給別人。

選 Gemini 的話，每位客戶第一次講話時會依人設自動設計一個台灣腔的聲音；不滿意可以在「更換」裡改描述，重新設計。
免費版送出的內容 Google 會拿去改進產品，公司正式使用請先在 AI Studio 開啟付費。

## 換成公司雲端
把 `.env.example` 複製成 `.env`，填 Azure OpenAI 金鑰，重開 `start.bat`，就能在「AI 大腦」切換。

## 放到網路上（Vercel）
想用手機或別的電腦練習，可以放到自己的 Vercel 網站，用通行碼登入。步驟寫在 [DEPLOY.md](DEPLOY.md)。
- 只限你本人使用
- ChatGPT 方案也能用：在本機版「AI 大腦」→「雲端版（Vercel）」按「登入並同步到雲端」，之後由雲端自己續期
- 雲端版的金鑰放在 Vercel 的環境變數，網頁上不能貼；「我的背景」、自訂情境、聲音設定存在雲端資料庫（Upstash），和這台電腦的分開

## 設定你的背景
左邊「我的背景」：填姓名、客戶怎麼叫你、職稱、公司、負責的商品、背景知識。
- 存在 `profile.json`，只留在這台電腦，不會上傳
- 客戶會用你填的稱呼叫你；教練和評分會照你的職稱判斷，並把「背景知識」當成正確答案（例如公司的手續費方案）
- `.env` 加上 `PROFILE_LOCKED=1`，考核期間就不能改

## 改客戶、改情境
左邊「情境設定」可以新增、修改、複製、刪除情境，也可以按「用 AI 幫我寫」先打草稿。
- 內建的三個情境不會被改掉：修改後的版本存在 `scenarios/custom/`，隨時可以「還原預設」
- 刪除的情境會先放到 `scenarios/custom/.trash/`，救得回來
- 隱藏設定（人設、隱藏資訊等）存好之後，畫面上不再顯示，學員看不到；要改就整段重寫，留空代表沿用原本的
- 聲音跟著頭像走：同一個頭像的客戶共用同一個聲音

情境文字裡可以用這些代稱，通話時會換成「我的背景」的內容：

| 代稱 | 換成 | 預設 |
| --- | --- | --- |
| `{業務姓}` | 姓 | 林 |
| `{業務全名}` | 姓名 | 林 |
| `{業務稱呼}` | 客戶怎麼叫你 | 小林 |
| `{職稱}` | 完整職稱 | 理財專員 |
| `{職稱簡稱}` | 簡稱 | 理專 |
| `{公司}` | 公司名稱 | 證券公司 |
| `{分公司}` | 分公司 | （空白） |
| `{年資}` | 例如「5 年」 | （空白） |

新的情境不要直接寫死「小林」這類名字，改用 `{業務稱呼}`。
