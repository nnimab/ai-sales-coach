# AI 理專對練教練（Demo）

## 怎麼用
1. 雙擊 `start.bat`，會自動用 Edge 打開
2. 選一位客戶 → 接聽 → 直接開口講（或打字）
3. 按「結束並評分」看報告

建議戴耳機，不然客戶的聲音會被麥克風收進去。

注意：選本機大腦時，客戶扮演和評分在本機跑；但「聽你說話」用的是瀏覽器內建語音辨識，聲音會送到 Google／微軟的雲端。要完全離線，之後要換成本機語音辨識。

## 即時對話（Gemini 3.8 Live）
左下角的「AI 大腦」選「Gemini 3.8 Live（即時對話）」，通話就像真的講電話：客戶講到一半你可以直接插話，它會停下來聽；不用按麥克風，也不用等停頓。
- 要先在「聲音設定」選 Gemini、貼上金鑰
- 麥克風整通電話都開著，點麥克風鍵可以靜音；一定要戴耳機，不然客戶會聽到自己的聲音而被打斷
- 即時教練用較快的 gemini-3.1-flash-lite，太忙或超過 9 秒就跳過那一輪（不會改用本機模型）；最後評分仍用 Gemini，太忙時改用本機模型
- 你說的話會即時送到 Google。免費版的額度小、尖峰時常塞車，正式使用請在 AI Studio 開啟付費

## 換成好聽的聲音
左邊選單「聲音設定」→ 選 ElevenLabs、Gemini 或雅婷 → 貼上 API 金鑰 → 幫每位客戶挑聲音。
金鑰會存在 `.env`，不要把 `.env` 傳給別人。

選 Gemini 的話，每位客戶第一次講話時會依人設自動設計一個台灣腔的聲音；不滿意可以在「更換」裡改描述，重新設計。
免費版送出的內容 Google 會拿去改進產品，公司正式使用請先在 AI Studio 開啟付費。

## 換成公司雲端
把 `.env.example` 複製成 `.env`，填 Azure OpenAI 金鑰，重開 `start.bat`，右上角就能切換。

## 設定你的背景
左邊「我的背景」：填姓名、客戶怎麼叫你、職稱、公司、負責的商品、背景知識。
- 存在 `profile.json`，只留在這台電腦，不會上傳
- 客戶會用你填的稱呼叫你；教練和評分會照你的職稱判斷，並把「背景知識」當成正確答案（例如公司的手續費方案）
- `.env` 加上 `PROFILE_LOCKED=1`，考核期間就不能改

## 改客戶、改情境
左邊「情境設定」可以新增、修改、複製、刪除情境，也可以按「用 AI 幫我寫」先打草稿。
- 內建的三個情境不會被改掉：修改後的版本存在 `scenarios/custom/`，隨時可以「還原預設」
- 刪除的情境會先放到 `scenarios/custom/.trash/`，救得回來
- 隱藏設定（人設、隱藏資訊等）存好之後，畫面上不再顯示，學員看不到；要改就整段重寫，留空代表沿用原本的
- 聲音跟著頭像走：同一個頭像的客戶共用同一個聲音

情境文字裡可以用這些代稱，通話時會換成「我的背景」的內容：

| 代稱 | 換成 | 預設 |
| --- | --- | --- |
| `{業務姓}` | 姓 | 林 |
| `{業務全名}` | 姓名 | 林 |
| `{業務稱呼}` | 客戶怎麼叫你 | 小林 |
| `{職稱}` | 完整職稱 | 理財專員 |
| `{職稱簡稱}` | 簡稱 | 理專 |
| `{公司}` | 公司名稱 | 證券公司 |
| `{分公司}` | 分公司 | （空白） |
| `{年資}` | 例如「5 年」 | （空白） |

新的情境不要直接寫死「小林」這類名字，改用 `{業務稱呼}`。
