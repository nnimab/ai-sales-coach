# scenarios

App 會把這一層的 `*.json` 當成「內建情境」（唯讀、跟著程式一起部署）。**現在這一層是空的**：2026-11-25 起情境改成兩種設定——

- **商品範本**：一檔商品一份（商品資料、白話重點、常見質疑和建議回應、不能說的話、審核狀態），在「情境設定 → 商品範本」建。
- **對練情境**：一位客戶一個（客戶是誰、什麼狀況），選一份商品範本當要賣的東西，在「情境設定 → 對練情境」建。

兩種都存在資料庫（雲端是 Redis，本機是 `templates.json` 和 `scenarios/custom/`），不放在這裡。

## samples/

原本的 15 個內建情境（3 個通用、12 個用 PoC 逐字稿做的，來源見 `samples/POC_SOURCES.md`）。App 不會讀這個資料夾，也不會部署上去；自動測試（`tests/_util.py` 的 `copy_project`）會把它們複製到測試用的專案裡當內建情境。

想把其中一個放回 App：把檔案複製回這一層再部署就是內建情境。
